# Superpowers Skills — חבילת סקילים הנדסיים מותקנים

> [!info] בעלים: **מערכת (צד-שלישי)** · נתיב: `.claude/skills/<skill>/`

## מה זה
חבילת סקילים כלליים שהותקנה לפרויקט (commit "Install Superpowers skills"). אלה
תהליכי-עבודה הנדסיים, לא חלק מצוות התוכן. מתועדים כקבוצה אחת מכיוון שהם תשתית
חיצונית ולא קבצי הצוות.

## הסקילים בחבילה
- **תכנון/ביצוע:** `brainstorming`, `writing-plans`, `executing-plans`,
  `subagent-driven-development`, `dispatching-parallel-agents`.
- **איכות:** `test-driven-development`, `systematic-debugging`,
  `verification-before-completion`, `requesting-code-review`, `receiving-code-review`.
- **Git/תהליך:** `using-git-worktrees`, `finishing-a-development-branch`,
  `using-superpowers`, `writing-skills`.

> [!note] כל סקיל יושב בתיקייה משלו עם `SKILL.md` (חלקם עם scripts/, references/,
> וקבצי בדיקה). לפירוט פנימי — ראו את הקבצים תחת `.claude/skills/<name>/`.
