# .obsidian/ — קונפיג ה-vault של Obsidian

> [!info] בעלים: **מערכת** · נתיב: `.obsidian/` (תיקייה)

## מה הקובץ עושה
תיקיית ההגדרות של אפליקציית Obsidian עבור ה-vault הזה. נוצרה כשהפרויקט נפתח כ-vault.
מכילה:
- `app.json`, `appearance.json` — העדפות תצוגה ועריכה.
- `core-plugins.json` — אילו תוספי ליבה פעילים.
- `workspace.json` — מצב חלונות/לשוניות אחרון.

קבצים אלה הם תשתית של הכלי, לא תוכן של הצוות. רלוונטיים לצפייה ב-[[File Docs/_index|מאגר התיעוד]]
ובשאר ה-vault דרך Obsidian (Graph View, wikilinks).
