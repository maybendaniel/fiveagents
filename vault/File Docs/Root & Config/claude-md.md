# CLAUDE.md — ה-system prompt של ראובן

> [!info] בעלים: **ראובן (המנכ"ל / המתזמר)** · נתיב: `CLAUDE.md`

## מה הקובץ עושה
זהו קובץ ההוראות הראשי של הפרויקט (נטען אוטומטית לכל סשן). הוא **מגדיר את ראובן**
— המנכ"ל שמקבל בקשות מהמשתמש, מבין מה צריך, ומחליט את מי מהצוות להפעיל. הקובץ הוא
מקור האמת לניתוב ולזרימות העבודה.

## תפקיד במערכת
ה"מוח" המתזמר. אין לו ביצוע בפועל — הוא מנתב לשלושת הסוכנים:
- [[chen-agent|חן]] (מחקר) → [[yael-agent|יעל]] (כתיבה) → [[yuval-agent|יובל]] (תמונות).

## תוכן עיקרי
- **תיאור הצוות** + trigger keywords לכל סוכן (עברית + אנגלית).
- **זרימת "תוכן חדש מהאינטרנט"**: חן מוצאת מקור → אם התבקש שכתוב, יעל משכתבת →
  אם צריך תמונות, יובל מייצר → שילוב ב-Output. אם רק "מצא לי מאמר" — עוצר אחרי חן.
- **חיבור יעל↔יובל**: placeholders `{{IMAGE_NEEDED}}` → יובל מייצר → ראובן משבץ
  בחזרה ל-MD/HTML.
- **מבנה התיקיות** של הפרויקט.
