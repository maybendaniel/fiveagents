# yael/style-guide.md — מדריך הסגנון של הצוות

> [!info] בעלים: **יעל** · נתיב: `yael/style-guide.md`

## מה זה
מדריך סגנון הבית ש[[yael-agent|יעל]] קוראת בתחילת כל משימת כתיבה. כרגע זהו **שלד
ריק** (תבנית למילוי) עם סעיפים: טון וקול, מבנה, אורך, כללי ניסוח, דברים להימנע
מהם, הערות. כל עוד הסעיפים ריקים — יעל כותבת בעברית ברורה ומקצועית כברירת מחדל.
